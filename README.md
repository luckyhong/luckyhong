## About Me

> **I turn product craft into executable systems — from iOS architecture to AI agent skills.**

Hi, I'm **Jihong Han** ([@luckyhong](https://github.com/luckyhong)) — an engineer shaped by years of **iOS product work**, now building **AI skills, creative automation, and evidence-grounded developer tooling**.

I care less about flashy demos and more about things that **run again tomorrow**:

- **Agent Skills** — package creative methods and engineering SOPs into reusable agent workflows
- **Architecture Intelligence** — turn real codebases into sourced, checkable architecture profiles
- **Creative Pipelines** — film commentary, animated shorts, hand-drawn story video systems
- **iOS Craft** — modular UIKit/Swift architecture, design systems, and product-grade UI structure
- **Knowledge Engineering** — structure messy ideas into tools agents can actually execute
